# Una Noche, Dos Ciudades — Invitación Privada

Invitación digital interactiva entregada por **Mapache Mapachoso**, con estética de gala
clásica inspirada en los grandes teatros de ópera.

La experiencia es lineal y breve:

1. **El escenario** — Mapache Mapachoso entra, hace una reverencia y entrega un sobre marfil con sello de lacre.
2. **La invitación** — el sobre se abre y despliega una carta de gala con los detalles de la velada, revelados progresivamente.
3. **La despedida** — Mapache Mapachoso hace una última reverencia junto a la carta.

No incluye reproductor de música, juegos ni ninguna otra actividad: termina cuando la
invitación ha sido leída.

## Stack

HTML, CSS y JavaScript puros (sin frameworks ni dependencias de compilación). Ilustración
del personaje en SVG inline. Listo para desplegarse como sitio estático en Netlify.

## Desarrollo local

Al ser un sitio estático, basta con abrir `index.html` en un navegador, o servirlo con
cualquier servidor estático, por ejemplo:

```bash
npx serve .
```
